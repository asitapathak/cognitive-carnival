_**Executive Summary**_
Intelligence is a biological engine driven by daily habits, emotional state, and environmental factors. This project utilizes machine learning to explore the intersection of human biology and cognitive performance, analyzing how sleep deprivation, emotional awareness, and stress physically dictate our brain's raw computing power.

This repository contains the source code, data processing pipelines, and front-end architecture for the interactive Streamlit dashboard. 

_**Scientific Methodology**_
This project processes clinical behavioral and cognitive metrics (derived from the Human Connectome Project framework) using three distinct machine learning approaches:

1. **Multiple Linear Regression (The Baseline):** Identifying the primary biological drivers for average, everyday problem-solving.
2. **K-Means Clustering (The Biological Override):** Unsupervised grouping that isolated a "Burnout" archetype—proving that severe sleep deprivation neutralizes superior cognitive hardware.
3. **Random Forest Classification (The Elite Bottleneck):** A predictive model built to sort the top 20% of logical performers, revealing that raw working memory and low environmental stress are the absolute gatekeepers to genius-level logic.
